# Employees

One file per employee. Create them with `/hire <role>`, which uses the template at `.claude/skills/hire/employee-template.md`. The roster with what each one owns is in `context/team.md`.

The blueprint ships with none. The first software project adds the Senior Technical Adviser (`new-project` or `import-project` skill; newest Fable model, maximum effort). Every other hire runs on the newest Opus model and is made when recurring work needs an owner.
