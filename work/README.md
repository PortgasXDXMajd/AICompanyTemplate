# work/

Deliverables that are not product code: landing page copy, outreach drafts, research write-ups, pricing options, content.

- One subfolder per area: `work/marketing/`, `work/research/`, `work/sales/`, `work/engineering/` (refinement candidates). Create them as needed.
- Name files so they sort and explain themselves: `YYYY-MM-DD-short-name.md`.
- Anything here that will be sent or published still needs CEO approval first. Evidence about real buyers goes in `customers/`, not here.
