# customers/

Evidence about real buyers. This folder is what separates facts from assumptions everywhere else in the company.

- One file per person or company: `customers/<name-or-handle>.md`, copied from `_template.md`.
- `insights.md` holds the patterns across files. Every pattern cites the files it came from.

Rules:

- Only record what was actually said or observed. Quote verbatim where you can and mark quotes as quotes.
- Note the source and date of every entry (call, email, forum post, review).
- Store the minimum personal data needed. No passwords, payment details, or private contact details that the person did not give for this purpose.
- Contacting anyone needs CEO approval first.
