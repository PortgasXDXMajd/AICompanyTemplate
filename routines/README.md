# routines/

Recurring procedures. A routine is a checklist any session can execute the same way every time. Run one by asking for it ("run the weekly review"). Routines are interactive in v1: they end with proposals the CEO has to agree to, so unattended runs are not supported.

Each routine states its trigger, owner, inputs, steps, and output. Add a new routine when the CEO asks for the same thing a third time. Keep routines short: if a step needs judgment calls explained at length, it belongs in a skill or a role file.
